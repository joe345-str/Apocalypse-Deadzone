# DEAD ZONE — Zombie Shooter

HTML5 zombie wave survival shooter.

## How to Play
Open `index.html` in any browser — no server needed.

Or visit the live GitHub Pages version.

## Features
- 3rd person top-down + 1st person FPS raycaster view
- 4 zombie types (Walker, Runner, Tank, Boss)
- Auto-aim system (TAB key or ⊕ AIM button)
- Apocalyptic environment: asteroids, earthquakes, fire, debris, ash
- Full Web Audio sound engine (no external files)
- Mobile touch controls
- HD canvas (devicePixelRatio support)

## Folder Structure
```
index.html      ← main game file
css/style.css   ← all styles
js/game.js      ← full game engine
README.md
```
